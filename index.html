IVI% — Tỷ trọng giá trị cá nhân trong tổ chức
IVI = phần trăm đóng góp trong tổng org value. Tổng = 100%.
// v6 IVI% formula raw = ProcVal×SW×0.35 + Skill×0.22 + Market×0.18 + NetworkScore×0.15 + Learn×0.10 // ProcVal×SW = Σ_steps(step.crit × proc.crit × SW(proc) × role_w) · resp=1.0, part=0.5 // SW(proc) = Σ_obj(obj.weight × influence) ← từ ma trận mục tiêu // NetworkScore= advice×0.35 + collab×0.30 + trust×0.25 + energy×0.10 ← từ khảo sát ONA IVI% = raw / Σ(all_raw) × 100 ← Tổng = 100%
